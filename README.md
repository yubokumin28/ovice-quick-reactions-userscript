# Ovice Quick Reactions(Tampermonkey 版)

Oviceのリアクションを、キーボードの Ctrl+Shift+数字・常に手前に出る小窓・Oviceの画面に浮かぶパネルから送れる、Tampermonkey 用のユーザースクリプトです。
キーとリアクションの割り当て、リアクションの名前もパネルから変えられます。

- 使い方と入れ方: https://yubokumin28.github.io/ovice-quick-reactions-userscript/
- インストール(Tampermonkey が必要): https://raw.githubusercontent.com/yubokumin28/ovice-quick-reactions-userscript/main/ovice-quick-reactions.user.js

保存はすべて利用者のブラウザの中(Tampermonkey の保存場所)だけで、外へ送るものはありません。
oVice 公式のツールではありません。
